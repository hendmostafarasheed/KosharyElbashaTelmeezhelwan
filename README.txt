Koshary El Basha Talmeez mini-site
- Open index.html for the invitation/home page.
- The three transparent hotspots sit over the original artwork buttons.
- "Open Menu" opens menu.html.
- Menu artwork can be enlarged with the button or by tapping the image.
- Chili bottle and opening mascot are CSS/SVG animations.
- Order and Offers currently open informational dialogs; add the restaurant's actual WhatsApp/order and offers URLs in site.js when available.
- All assets are local, so the site can be previewed offline after extracting the ZIP.


MUSIC UPDATE: The uploaded MP3 is included as invitation-song.mp3 and is set to loop on both the home invitation and menu pages. Browsers on phones often block autoplay with sound until the visitor taps the music button; use the floating button if playback does not start automatically.
